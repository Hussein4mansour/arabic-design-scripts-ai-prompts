Open-source automation scripts, lightweight creative utilities, and structured AI prompt frameworks tailored for **Arabic typography, calligraphy, and Right-to-Left (RTL) visual design**.

## Why This Project Exists
Most open-source design automation scripts and AI prompt libraries are designed primarily for Latin scripts. Arabic graphic designers, calligraphers, and motion creators often face manual, repetitive tasks when preparing vector calligraphy, handling RTL text layers, or generating consistent culturally accurate AI visuals. This repository bridges that gap with practical, open-source tools and tested creative workflows.

## Key Features
- **Adobe ExtendScript Utilities:** Automation scripts for Adobe Illustrator and Photoshop to streamline Arabic text layer handling, glyph ligatures, batch RTL asset exporting, and vector anchor-point cleanup for calligraphy styles (*Thuluth*, *Diwani*, *Kufic*, and *Sunbuli*).
- **Structured AI Prompt Frameworks:** Parameterized, tested prompt templates for AI image and motion generation—engineered to preserve clean negative space for Arabic kinetic typography and brand identity layouts.
- **Bilingual Documentation:** Practical usage guides in English and Arabic to make automation accessible to the wider MENA creative community.
